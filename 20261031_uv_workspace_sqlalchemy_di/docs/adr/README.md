# アーキテクチャ決定記録

ADR(Architecture Decision Record)は、設計上の決定を理由つきで残す短い文書です。
`shop_core` について、決定の背景と、選ばなかった案を記録します。
1 つの決定を 1 ファイルに書き、書いた後は書き換えず、追記だけにします。
決定を変えるときは新しい ADR を作り、ステータスを「置換」にして、元の ADR を指します。
元の ADR のステータスにも、置き換えた ADR の番号を書き足します。

| 番号 | タイトル | ステータス |
|---|---|---|
| [0001](0001-shop-core-owned-shared-library.md) | 共有パーツを基盤が所有するライブラリ shop_core として配る | 置換(0002) |
| [0002](0002-shared-library-contract.md) | 基盤ライブラリの契約 | 採用 |
